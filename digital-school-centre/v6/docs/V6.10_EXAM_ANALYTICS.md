# V6.10 — JSLH Examination Analytics

## Included
- School-authenticated examination workspace using the V6 Supabase client configuration.
- School membership resolution and school-scoped reads/writes through the existing RLS-protected V6 tables.
- Examination creation, learning-area components and the existing assessment status RPC workflow.
- Individual result entry with numeric range validation and upsert by assessment/component/learner.
- CSV import with row validation before writes, admission-number and component-title matching, 100-row batches, and rejection report.
- Automatic school overview, learning-area means, median, highest, lowest, population standard deviation, grade/stream comparisons and configurable internal band distribution.
- Learner merit lists with competition ranking for ties and transparent missing-result warnings.
- Printable individual and batch report cards; immutable report-card snapshots for approved/locked assessments.
- CSV exports for detailed analysis and merit lists.

## Existing database objects used
This module uses the V6 schema already present in migrations 001–006:
- school_memberships, schools
- academic_years, academic_terms, school_grades, school_streams
- learning_areas, learners
- school_assessments, assessment_components, assessment_marks
- report_card_snapshots
- set_assessment_status(p_assessment_id, p_status) RPC

No database migration is required for this UI package. Do not run migrations against the existing production Junior School Learning Hub database.

## Calculation rules
- Percentage = raw_score / maximum_score × 100.
- Missing numeric scores are excluded from means, medians, standard deviations and ranking; they are never silently converted to zero.
- Subject/learning-area statistics use recorded numeric component rows.
- Learner ranking uses the unweighted mean of numeric component percentages actually recorded for that learner. Learners with different subject counts are not directly comparable; the UI discloses this.
- Equal means share a rank (competition ranking).
- The internal four-band profile is illustrative and browser-local, editable by the school. It is not represented as official KNEC/KJSEA grading.
- Descriptor, rubric, portfolio and competency evidence is displayed as qualitative evidence and not converted into a numeric percentage.

## Workflow
Draft → Open → Submitted → Moderation → Approved → Locked. The database RPC and triggers enforce transitions and prevent changes to finalised marks. Report snapshots are append-only; the UI does not overwrite historical snapshots.

## Release and safety gates
- Development branch and Deploy Preview only; do not merge into main or deploy to the production domain.
- Test using a dedicated V6 development Supabase project and fictional learner records.
- Verify RLS and role access for at least two independent schools and teacher subject assignments.
- Validate CSV imports, grading configuration, workflow transitions, ranking denominators, report printing and snapshot immutability before production consideration.
- The current module does not send SMS, perform official KNEC certification, or replace professional teacher judgement.
