# Digital School Centre V6.9

This package adds a functional automatic timetable draft generator at `app/timetable.html`. Open `app/index.html` and choose **Automatic timetable generator**, or open the timetable page directly.

1. Configure school days, teaching periods, duration and breaks.
2. Add teachers and their weekly maximum periods.
3. Add grade/stream teaching groups.
4. Add each learning area's weekly period requirement and assigned teacher/room.
5. Generate and inspect validation and unplaced periods.
6. Export CSV or print / save as PDF.

The timetable draft is stored locally in the current browser. This is not yet connected to live Supabase persistence or production publishing. Keep using a development copy and fictional/test data until server-side publication and RLS checks are completed. Existing V6.8 modules and migrations are retained.
